# 授業データの入れ方（無料の道具だけで）

授業カタログの検索結果をコピーし、無料の AI チャットで表にして、GitHub に置くだけで時短割に反映されます。
Claude Code も有料プランも要りません。使うのは次の4つで、どれも無料です。

- ブラウザ（授業カタログ・シラバスを見る）
- AI チャット（claude.ai の無料プランなど）
- Google スプレッドシート（確認と追記）
- GitHub と Vercel（今のアカウントのまま）

> 守ること：ページを見てコピーするのは人の手で行う（プログラムで自動取得しない）。シラバスの文章はそのまま使わず、曜日・時限・単位数などの事実だけを使う。

---

## 1. 授業カタログからコピーする

1. ブラウザで授業カタログを開き、年度・学期・キーワードで検索する
2. 検索結果のページで全体を選択（Ctrl+A / ⌘+A）してコピーする
3. 何ページかに分かれていれば、ページごとに次の手順をくり返す

3年生が取りそうな授業を、まず1学期分（30〜60件）入れれば検証には十分です。

## 2. AI チャットで表（CSV）にする

claude.ai の無料プランなどで新しいチャットを開き、**下の「AIに渡す指示文」を貼ってから**、コピーした検索結果を続けて貼ります。
返ってきた CSV（1行目が `時間割コード,授業名,…` で始まるもの）をコピーします。

## 3. スプレッドシートで確認・追記する

1. Google スプレッドシートで新しいシートを開き、A1 セルに CSV を貼り付ける
   - 1列にまとまってしまったら、メニューの「データ」→「テキストを列に分割」→ 区切り文字「カンマ」
   - 初めてなら `data/courses.template.csv` の中身を先に貼ると、列の並びと書き方の例が分かります
2. 空欄を埋める（特に **区分** は必須）

| 列 | 必須 | 書き方 |
| --- | --- | --- |
| 時間割コード・授業名・教員 | ○ | そのまま |
| 学期 | ○ | 前期／後期／通年 |
| 曜日 | ○ | 月〜金（「月曜」でも可） |
| 時限 | ○ | 1〜5（「2限」でも可） |
| 単位数 | ○ | 数字 |
| 区分 | ○ | 基幹教育科目／外国語科目／学部基礎科目／専門科目／演習（履修要項で確認） |
| 対象学年 | | `2,3,4` や `2-4`。空欄なら全学年 |
| 出席必須・教科書購入必須 | | はい／いいえ／空欄（空欄＝「不明」で、足切りでは除外されない） |
| 試験の持ち込み | | 持ち込み可／持ち込み不可／試験なし／空欄 |
| 成績評価 | | 期末試験70%・レポート30% |
| 概要 | | 自分の言葉で1行（シラバスの文章を写さない） |
| 興味タグ | | マーケティング・会計・ファイナンス・経営戦略・国際ビジネス・データ分析 から選び、`・` で区切る |

3. 「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」で保存し、ファイル名を **`courses.csv`** にする

## 4. GitHub に置く

1. ブラウザで GitHub の `relic-intern` リポジトリを開き、`data` フォルダに入る
2. 「Add file」→「Upload files」で `courses.csv` をアップロードする（2回目からは同じ名前で上書き）
3. 下の「Commit changes」を押す（`main` に直接でかまいません）

## 5. 反映を確認する

- 数分で Vercel が自動でビルドし、公開サイトの授業データが入れ替わります
- **入力ミスがあると Vercel のビルドが失敗**し、前の公開版がそのまま残ります。Vercel の画面で失敗したデプロイを開き、ログ（Build Logs）を見ると、次のように行番号つきで直す場所が出ています

```
[import:courses] data/courses.csv に 2 件の入力ミスがあります。
  - 5行目「区分」：「専門」は次のどれかにしてください：基幹教育科目／外国語科目／学部基礎科目／専門科目／演習
  - 9行目「時限」：「6」は 1〜5 の数字にしてください
```

  スプレッドシートで直して、4 をもう一度行ってください。

- `data/courses.csv` が無いあいだは、今のダミーデータ（`src/data/courses.json`）がそのまま使われます

## 卒業要件（必要単位数）を直すとき

`src/data/requirements.json` を GitHub の画面で開き、鉛筆アイコン（Edit）から数字を直して「Commit changes」を押します。
`min_credits` が区分ごとの必要単位数です。区分の名前を変えると、CSV の「区分」で使える値も変わります。
